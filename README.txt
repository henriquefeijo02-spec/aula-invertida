# 🧠 Equipe 3 - Os Agregadores do Reduce

## 🎯 Objetivo
Demonstrar como substituir código imperativo com variáveis mutáveis por uma abordagem funcional usando `reduce()` em JavaScript.

---

## ⚙️ Conceito

A função `reduce()` percorre um array e o transforma em um único valor.

### Sintaxe:
```js
array.reduce((acumulador, valorAtual) => novoValor, valorInicial);
